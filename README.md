# Spellcasting

Spellcasting is library mod and engine for resolving abstract and data-driven spells in Minecraft.

Inspired by Ars Magicka, Thaumcraft, EvilCraft, BloodMagic, Ars Nouveau, Electroblob's Wizardy, Witchery, Irons', Mahou Tsukai and more.
